Introduction
3
A real-time voice agent closes a continuous perception →  action loop: it
hears speech, reasons over intent, and executes OS-level actions directly
on a device (not just returning text like a chatbot).
Audio is captured continuously, mapped to intent (ideally via a native
audio-understanding model rather than a slower STT →  LLM →  TTS
cascade), turned into executable commands, and run at the full OS level   

=== Slide 4 ===
t
4
After each action, the agent re-reads screen state (via screenshot/vision model or
accessibility tree) and self-corrects on mismatch, since there's no human in the
loop to catch errors.
Native audio-understanding models are preferred over the cascaded STT →  LLM →
TTS pipeline, since each stage in a cascade adds latency that compounds end-to-

Existing Techniques 
Command-based: fast but rigid, no unstructured speech
Browser agents: web-only, no OS/native access
Cascaded STT → LLM → TTS: latency compounds per stage
Intent classifiers: text-only, not real-time OS actions
Voice assistants: edge = fixed intents; cloud = needs connectivity,
English-first.

PROBLEM  STATEMENT
We are going to build a voice-native, self-correcting OS agent to give fully
paralyzed individuals independent, real-time computer access without
needing hands, browsers, or English-only cloud tools.

=== Slide 21 ===
7
9
21
OBJECTIVES
1.Develop a hybrid agent architecture capable of operating in both offline (local LLM) and online modes,
achieving an average query inference time of ≤15 seconds across both modes.
2.Implement a model-switching layer that allows users to select and swap between LLMs — including
domestic models such as Sarvam AI — to expand support for Indian regional languages beyond
English-only interaction.
3.Improve agent response efficiency by implementing a caching mechanism for frequently used user
workflows, reducing repeated-task execution time by a measurable margin compared to
uncached execution.

=== Slide 24 ===
CONCLUSION
This system gives fully paralyzed individuals
independent, full-OS control via real-time, verified,
self-correcting speech-to-action — going beyond
rigid command grammars with LLM code
generation, and beyond blind execution with
screen-state checks that self-correct without
human fallback.
It's also built for India and built to be free, with
regional-language support (Sarvam AI) and offline
mode. Future work: dysarthric speech adaptation,
hybrid deployment, and hardware-aware model
selection. 24
